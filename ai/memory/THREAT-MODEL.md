# Eldorado-AI Memory Threat Model

## Assets

- user memories
- user preferences
- project information
- conversation-derived knowledge
- authentication information
- authorization state
- secrets

## Threat Actors

- malicious user
- compromised external website
- malicious document
- compromised plugin/tool
- compromised dependency
- unauthorized local process
- attacker with stolen credentials

## Primary Threats

1. Memory poisoning
2. Prompt injection through retrieved memory
3. Unauthorized memory access
4. Cross-user data leakage
5. Sensitive information disclosure
6. Stale or incorrect memory
7. Memory deletion attacks
8. Memory-based privilege escalation

## Security Objective

Eldorado should become more useful through experience without allowing its accumulated experience to become an uncontrolled source of authority.
